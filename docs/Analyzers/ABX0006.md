# ABX0006 - Unconditional self recursion
<!-- sources -->
Sources: [UnconditionalSelfRecursionAnalyzer.cs](./../../Abaddax.Roslyn.Analyzers/Analyzers/UnconditionalSelfRecursionAnalyzer.cs)
<!-- sources -->
<!-- links -->
[Link_StackOverflowException]: https://learn.microsoft.com/en-us/dotnet/api/system.stackoverflowexception

This analyzer report unconditional self recursion, as this will cause a [StackOverflowException][Link_StackOverflowException].

```csharp
Task WorkAsync()
{
    await WorkAsync(); // non-compliant
}

// Should be
async Task WorkAsync()
{
    if (cond)
        await  WorkAsync();
}
```

The analyzer also takes `base` calls into account. So the following is valid and will not report:
```csharp
Task WorkAsync()
{
    await base.WorkAsync();
}
```

Also property getters and setters are supported.

# Known limitations

The analyzer only detects if there is at least one exit path out of the function that exits without a self recursion.
It does not check whether the path can actually be reached given the parameters of a function. (semantic error)

Example:
```csharp
void Boom(int i)
{
   if (i > 0)
      Boom(i + 1);
}
```
Here the analyzer will not report because there is a possible return path without recursion.
However, only if `i` is negative. If `i` is once positive, it will never get negative, hence causing a [StackOverflowException][Link_StackOverflowException].
