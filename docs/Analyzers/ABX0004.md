# ABX0004 - Use async EF Core methods inside async function

Methods that return awaitable types such as [Task][Link_Task] or [ValueTask][Link_ValueTask] should use the async EF Core query terminators.
([FirstAsync][Link_FirstAsync], [ToArrayAsync][Link_ToArrayAsync], ... from [EntityFrameworkQueryableExtensions][Link_EntityFrameworkQueryableExtensions])

```csharp
Task WorkAsync()
{
    _ = _db.Entities.First(); // non-compliant
}

// Should be
async Task WorkAsync()
{
    _ = _await _db.Entities.FirstAsync();
}
```
