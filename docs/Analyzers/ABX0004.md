# ABX0004 - Use async EF Core methods inside async function
<!-- sources -->
Sources: [EfCorePreferAsyncCallAnalyzer.cs](./../../Abaddax.Roslyn.Analyzers/Analyzers/EfCorePreferAsyncCallAnalyzer.cs)
<!-- sources -->

Methods that return awaitable types such as Task or ValueTask should use the async EF Core query terminators.
(`FirstAsync`, `ToArrayAsync`, ... from [EntityFrameworkQueryableExtensions](https://learn.microsoft.com/en-us/dotnet/api/microsoft.entityframeworkcore.entityframeworkqueryableextensions))

```csharp
Task WorkAsync()
{
    _ = _db.Entities.First(); // non-compliant
}

// Should be
async Task WorkAsync()
{
    _ = _await _db.Entities.FirstAsync();
}
```
