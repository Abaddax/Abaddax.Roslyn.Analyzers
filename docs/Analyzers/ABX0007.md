# ABX0007 - 'ThenInclude' formatting
<!-- sources -->
Sources: [EfCoreThenIncludeFormattingAnalyzer.cs](./../../Abaddax.Roslyn.Analyzers/Analyzers/EfCoreThenIncludeFormattingAnalyzer.cs)
<!-- sources -->
<!-- links -->
[Link_ThenInclude]: https://learn.microsoft.com/en-us/dotnet/api/microsoft.entityframeworkcore.entityframeworkqueryableextensions.theninclude
[Link_Include]: https://learn.microsoft.com/en-us/dotnet/api/microsoft.entityframeworkcore.entityframeworkqueryableextensions.include
<!-- links -->

[ThenInclude][Link_ThenInclude]'s should be either on the same line as the [Include][Link_Include] or indented one level for better readability.

```csharp
Task WorkAsync()
{
    _ = _db.Entities
        .Include(x => x.Related)
        .ThenIncluded(x => x.Related2) // non-compliant
        .First();
}

// Should be
async Task WorkAsync()
{
    _ = _db.Entities
        .Include(x => x.Related).ThenIncluded(x => x.Related2)
        .First();
    //or
    _ = _db.Entities
        .Include(x => x.Related)
            .ThenIncluded(x => x.Related2)
        .First();
}
```

## Configuration

```ini
# The analyzer take the 'indent_size' into account
# default: 4
indent_size = 2
```
