# ABX0003 - Use async overload in async function
<!-- sources -->
Sources: [SuggestAsyncOverloadAnalyzer.cs](./../../Abaddax.Roslyn.Analyzers/Analyzers/SuggestAsyncOverloadAnalyzer.cs)
<!-- sources -->

Methods that return awaitable types such as Task or ValueTask should use non blocking overloads.

```csharp
SemaphoreSlim _semaphore = new(1);

Task WorkAsync()
{
    _semaphore.Wait(); // non-compliant
}

// Should be
async Task WorkAsync()
{
    await _semaphore.WaitAsync();
}
```

Does not report, if the only alternative is the current function itself. ([ABX0006](./ABX0006.md))
