# ABX0001 - Async method should accept CancellationToken
<!-- sources -->
Sources: [CancellationTokenAnalyzer.cs](./../../Abaddax.Roslyn.Analyzers/Analyzers/CancellationTokenAnalyzer.cs)
<!-- sources -->
<!-- links -->
[Link_Task]: https://learn.microsoft.com/en-us/dotnet/api/system.threading.tasks.task
[Link_ValueTask]: https://learn.microsoft.com/en-us/dotnet/api/system.threading.tasks.valuetask
[Link_CancellationToken]: https://learn.microsoft.com/en-us/dotnet/api/system.threading.cancellationtoken
<!-- links -->

Methods that return awaitable types such as [Task][Link_Task] or [ValueTask][Link_ValueTask] should have a [CancellationToken][Link_CancellationToken] parameter, 
so they can pass cancellation down to inner function calls.

```csharp
Task WorkAsync() => Task.CompletedTask; // non-compliant

// Should be
Task WorkAsync(CancellationToken cancellationToken) => Task.CompletedTask;
```
