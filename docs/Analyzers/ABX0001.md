# ABX0001 - Async method should accept CancellationToken
<!-- sources -->
Sources: [CancellationTokenAnalyzer.cs](./../../Abaddax.Roslyn.Analyzers/Analyzers/CancellationTokenAnalyzer.cs)
<!-- sources -->

Methods that return awaitable types such as Task or ValueTask should have a `CancellationToken` parameter, 
so they can pass cancellation down to inner function calls.

```csharp
Task WorkAsync() => Task.CompletedTask; // non-compliant as there is no CancellationToken parameter

// Should be
Task WorkAsync(CancellationToken cancellationToken) => Task.CompletedTask;
```
