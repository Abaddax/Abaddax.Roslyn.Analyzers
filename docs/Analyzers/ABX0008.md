# ABX0008 - Suppression requires a justification
<!-- sources -->
Sources: [SuppressionJustificationAnalyzer.cs](./../../Abaddax.Roslyn.Analyzers/Analyzers/SuppressionJustificationAnalyzer.cs)
<!-- sources -->

Diagnostic suppressions should always have a justification for clarity and traceability. for better readability.

```csharp
[System.Diagnostics.CodeAnalysis.SuppressMessage("Example", "EXAMPLE1")] // non-compliant
Task WorkAsync() => Task.CompletedTask;

// Should be
[System.Diagnostics.CodeAnalysis.SuppressMessage("Example", "EXAMPLE1", Justification = "Reason")]
Task WorkAsync() => Task.CompletedTask;
```

Is is also possible to check `pragma`-style suppressions, however this is not enabled by default.

```csharp
// non-compliant

#pragma warning disable EXAMPLE1 

// Should be

// Reason
#pragma warning disable EXAMPLE1 
```

## Configuration

```ini
# Include pragmas in the analysis
# default: false
dotnet_code_quality.ABX0008.include_pragmas = true
```
```xml
<PropertyGroup>
  <AbaddaxRoslynAnalyzersABX0008IncludePragmas>true</AbaddaxRoslynAnalyzersABX0008IncludePragmas>
</PropertyGroup>
```
