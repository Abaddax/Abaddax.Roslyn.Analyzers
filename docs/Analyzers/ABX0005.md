# ABX0005 - Explicitly qualify the tracking behavior when using EF Core
<!-- sources -->
Sources: [EfCoreExplicitTrackingAnalyzer.cs](./../../Abaddax.Roslyn.Analyzers/Analyzers/EfCoreExplicitTrackingAnalyzer.cs)
<!-- sources -->

When using EF Core specify the tracking behavior explicitly for better readability.
This helps showing the intent and thereby also ensures that `AsNoTracking` wasn't simply forgotten.

```csharp
Task WorkAsync()
{
    _ = _db.Entities.First(); // non-compliant
}

// Should be
async Task WorkAsync()
{
    _ = await _db.Entities.AsTracking().FirstAsync();
}
```
