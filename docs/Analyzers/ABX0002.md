# ABX0002 - Async method should end with 'Async'
<!-- sources -->
Sources: [AsyncSuffixAnalyzer.cs](./../../Abaddax.Roslyn.Analyzers/Analyzers/AsyncSuffixAnalyzer.cs)
<!-- sources -->

Methods that return awaitable types such as Task or ValueTask should have an 'Async' suffix.

```csharp
Task Work() => Task.CompletedTask; // non-compliant

// Should be
Task WorkAsync() => Task.CompletedTask;
```

Automatically ignores `Main` (entrypoint) for executables.

## Configuration

```ini
# Ignore test functions (MSTest, NUnit, XUnit)
# default: true
dotnet_code_quality.ABX0001.ignore_tests = false

# Ignore ASP.NET controller routes
# default: true
dotnet_code_quality.ABX0001.ignore_controllers = false
```
```xml
<PropertyGroup>
  <AbaddaxRoslynAnalyzersABX0002IgnoreTests>false</AbaddaxRoslynAnalyzersABX0002IgnoreTests>
  <AbaddaxRoslynAnalyzersABX0002IgnoreControllers>false</AbaddaxRoslynAnalyzersABX0002IgnoreControllers>
</PropertyGroup>
```
