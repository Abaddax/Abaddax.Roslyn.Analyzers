# ABX1004 - Suppresses unused CancellationToken parameter warnings

This suppressor can suppress unused parameter warnings for [CancellationToken][Link_CancellationToken] parameters in method declarations. ([IDE0060][Link_IDE0060])
Otherwise there would be conflicts with [ABX0001](../Analyzers/ABX0001.md).
Also leaving an unused [CancellationToken][Link_CancellationToken] parameters could minimize later API changes.

### How the suppressor works

```csharp
Task WorkAsync(CancellationToken cancellationToken) // Unused parameter warnings are suppressed for ' cancellationToken'
{
    return Task.CompletedTask;
}
```

## Configuration

```ini
# Disable the suppressor
# default: true
dotnet_code_quality.ABX1004.enabled = false
```
```xml
<PropertyGroup>
  <AbaddaxRoslynAnalyzersABX1004Enabled>false</AbaddaxRoslynAnalyzersABX1004Enabled>
</PropertyGroup>
```
