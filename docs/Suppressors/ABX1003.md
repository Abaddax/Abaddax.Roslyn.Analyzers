# ABX1003 - Suppresses unused variable warnings for exceptions

This suppressor can suppress unused variable warnings for exception. ([CS0168][Link_CS0168], [IDE0059][Link_IDE0059])
The warning in these cases are irrelevant, because the produces IL is the exact same.
But removing the variable might harm debugging, because the exception can now not be analyzed easily.

### How the suppressor works

```csharp
try
{
    ...
}
catch (Exception ex) // Unused variable warnings are suppressed for 'ex'
{
    ...
}
```

## Configuration

```ini
# Disable the suppressor
# default: true
dotnet_code_quality.ABX1003.enabled = false
```
```xml
<PropertyGroup>
  <AbaddaxRoslynAnalyzersABX1003Enabled>false</AbaddaxRoslynAnalyzersABX1003Enabled>
</PropertyGroup>
```
