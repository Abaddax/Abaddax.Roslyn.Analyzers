# ABX1005 - Suppresses warning for visible protected readonly fields
<!-- sources -->
Sources: [ProtectedReadonlyFieldSuppressor.cs](./../../Abaddax.Roslyn.Analyzers/Suppressors/ProtectedReadonlyFieldSuppressor.cs)
<!-- sources --><!-- links -->
[Link_CA1051]: https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1051
<!-- links -->

This suppressor can suppress warnings for visibly readonly field in classes. ([CA1051][Link_CA1051])
Declaring a visibly readonly field in classes might be an allowed coding convention.

### How the suppressor works

```csharp
public class BaseClass
{
    protected readonly ILogger _logger; // Visibly field warnings are suppressed for '_logger'
}
```

## Configuration

```ini
# Enable the suppressor
# default: false
dotnet_code_quality.ABX1005.enabled = true
```
```xml
<PropertyGroup>
  <AbaddaxRoslynAnalyzersABX1005Enabled>true</AbaddaxRoslynAnalyzersABX1005Enabled>
</PropertyGroup>
```
