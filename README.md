# Abaddax.Roslyn.Analyzers

**Abaddax.Roslyn.Analyzers** is a collection of C# Roslyn analyzer that uses static analysis to detect undesired code patterns.

## Installation

Install the NuGet package [Abaddax.Roslyn.Analyzers](https://www.nuget.org/packages/Abaddax.Roslyn.Analyzers/).

# Analyzers

You can find a list of all the analyzers in [docs](./docs/README.md).

# Remarks

This package is still in an early stage of development, and although there are many tests for the analyzers, some issues may still occur in specific scenarios.
